# Working in the Site Editor

Canvas is a block theme, so site-wide editing happens in the WordPress Site Editor at **Appearance > Editor**.

## Styles

Use **Styles** to choose or adjust site-wide colors, typography, spacing and other design settings.

The palette has 13 colors: Primary, the accent; Base to Base 7, from white through the light grays; and Contrast to Contrast 5, from the heading color through the dark grays. Every pattern reads its colors from the palette, so a change to Contrast recolors the dark bands and dark headers too. The default typeface is Inter.

Style changes affect the whole site unless a block, template or page has more specific settings applied.

## Block Styles

Canvas adds styles to core blocks. Each appears in the block's **Styles** panel:

- Accordion: Minimal
- Button: Outline Light and Fill Primary
- List: Check Primary, Check Circle Primary, Check Neutral and Check Circle Neutral
- Navigation: Hover Primary and Hover Pill
- Separator: Dotted and Thin
- Image: Rounded Full and Boxed
- Video: Boxed
- Cover: Blur Image Less and Blur Image More
- Post Terms: Chip and Inline
- Tag Cloud: Chip
- Post Navigation Link: Stacked
- Post Excerpt: Truncate 2 Lines and Truncate 3 Lines
- Code and Preformatted: Dark

## Templates

Templates control page types such as pages, posts, archives, search results and 404 pages. Canvas includes 12; [Patterns and Templates](patterns-and-templates.md) names them.

When you edit a template, you are changing the structure used by every page or post that relies on that template.

## Template Parts

Template parts are site sections shared across templates. Canvas has five: Header, Footer, Sidebar, Mobile Menu and Mobile Menu Dark.

Editing a template part affects every template where that part appears.

## Saving Changes

The Site Editor saves template and style changes separately from normal post or page content.

Before saving, WordPress shows which templates, template parts or styles are about to be updated. Review that list when making site-wide changes.

## If Changes Do Not Appear

If a change does not appear on the front end, clear your browser cache and your caching plugin's cache, then refresh the page.

Saved Site Editor customizations also override theme defaults. Check whether the template, template part or style has already been customized in the editor.
