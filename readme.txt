A Full Site Editing WordPress block theme for sites that look designed, not assembled. Templates, patterns, typography, and color - one coherent system.

== Description ==

For solo developers, freelancers, and small teams building polished sites without starting from zero.

Start closer to finished. Balanced type, deliberate spacing, flexible templates, and cohesive patterns give every build a clear design foundation from the first page.

Choose from eleven style variations, shape the site in the editor, and keep momentum without losing the design thread.

== Installation ==

1. Login to your WordPress installation and go to Appearance > Themes > Add New > Upload Theme.
2. Click Choose File and browse to the theme's ZIP file on your computer. Click Install Now.
3. Click Activate to get started with your new theme right away.

== Fonts ==

The following fonts are loaded locally from the theme's assets:

- Inter: Used for body text and headings in the default style. Available in normal and italic at 400, 500, 600, and 700 weights. Source: [Google Fonts](https://fonts.google.com/specimen/Inter) licensed under [SIL Open Font License 1.1](https://scripts.sil.org/OFL).

- DM Sans: Used by the Refined Sans style variation. Source: [Google Fonts](https://fonts.google.com/specimen/DM+Sans) licensed under [SIL Open Font License 1.1](https://scripts.sil.org/OFL).

- Space Grotesk: Used by the Expressive style variation. Source: [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk) licensed under [SIL Open Font License 1.1](https://scripts.sil.org/OFL).

- Source Serif 4: Used by the Editorial style variation. Source: [Google Fonts](https://fonts.google.com/specimen/Source+Serif+4) licensed under [SIL Open Font License 1.1](https://scripts.sil.org/OFL).
