# Support

Canvas support runs through GitHub Issues.

## Get Help

Open an issue at [Origin Canvas GitHub Issues](https://github.com/origin-blocks/origin-canvas/issues).

A tool that moves saved content from the 1.3.1 color, spacing and line-height names to the 1.4.0 names is available on request. Open an issue and ask for it.

## What to Include

Include the WordPress version, the Canvas version, the browser and where the issue appears.

Screenshots help when the issue is visual. Steps to reproduce help when the issue depends on a specific editing flow.

## Before Opening an Issue

Check that the site meets the theme's requirements: WordPress 7.0 or later and PHP 7.4 or later. Canvas 1.5.0 is tested up to WordPress 7.1.

When practical, test with only Canvas active and no plugins enabled.

Also check whether the issue comes from custom Site Editor changes, a plugin or content added to a specific page or template. If your site ran Canvas 1.3.1 and a color looks wrong after the update, read [Updating from 1.3.1](getting-started.md#updating-from-131) first.
